# Manifest für Digitale Verwaltung

## Wir glauben an:

### 1. **Bürger über Bürokratie**
Technologie dient den Menschen, nicht umgekehrt. Jede digitale Lösung muss:
- Zeit sparen statt Zeit kosten
- Transparenz schaffen statt verwirren
- Zugänglich sein für alle

### 2. **Offenheit über Absicherung**
Open Source ist keine Option, sondern Pflicht für öffentliche Software:
- Jeder Code muss einsehbar sein
- Jede Entscheidung muss nachvollziehbar sein
- Kein Vendor Lock-in

### 3. **Einfachheit über Komplexität**
Die beste Lösung ist die, die niemand merkt:
- Modulare Systeme statt Monolithen
- Klare Schnittstellen statt versteckter Abhängigkeiten
- Automatisierung statt manueller Arbeit

### 4. **Resilienz über Geschwindigkeit**
Stabile Systeme sind wichtiger als schnelle Releases:
- Automatisierte Tests vor jedem Deploy
- Health Checks für alle Dienste
- Rollback-Fähigkeit bei Problemen

### 5. **Souveränität über Komfort**
Datenhoheit bleibt bei der Kommune:
- On-Premise Deployment
- DSGVO-Konformität
- Keine Abhängigkeit von US-Cloud-Anbietern

---

## Was wir ablehnen:

❌ **Blackbox-Software** — Wenn niemand versteht, wie es funktioniert  
❌ **Manuelle Prozesse** — Wenn Menschen tun, was Maschinen können  
❌ **Vendor Lock-in** — Wenn Wechsel unmöglich wird  
❌ **Undurchsichtige Algorithmen** — Wenn Entscheidungen nicht erklärbar sind  
❌ **Cloud-only** — Wenn Datenhoheit verloren geht  

---

## Unsere Versprechen:

✅ **Jeder Code ist Open Source** — GPL-3.0 oder ähnlich  
✅ **Jede Änderung ist getestet** — ≥ 90% Testabdeckung  
✅ **Jede Entscheidung ist dokumentiert** — ADRs für Architektur  
✅ **Jeder Prozess ist automatisiert** — CI/CD für alles  
✅ **Jedes Modul ist ersetzbar** — Unix-Prinzip: Do one thing well  

---

## Wie wir arbeiten:

```
Problem → Einfache Lösung → Automatisierte Tests → Transparente Dokumentation → Deployment
```

Nicht:

```
Problem → Komplexes System → Manuelle Tests → Undokumentiert → "Es funktioniert"
```

---

## Für wen wir arbeiten:

- **Kommunen** — Die Bürger verdienen bessere Verwaltung
- **Verwaltungen** - Mitarbeiter verdienen bessere Werkzeuge
- **Bürger** — Die deserve einfache digitale Services
- **Startups** — Die mit offenen Standards innovieren können

---

## Unser Commitment:

Wir bauen nicht nur Software. Wir bauen:
- **Vertrauen** durch Transparenz
- **Unabhängigkeit** durch Open Source
- **Zukunftsfähigkeit** durch Modularität
- **Qualität** durch Automatisierung

---

## Call to Action:

Wenn du in einer Kommune, Verwaltung oder Behörde arbeitest:

1. **Frag nach Open Source** — Bevor du proprietäre Software kaufst
2. **Frag nach API** — Bevor du manuelle Prozesse akzeptierst
3. **Frag nach On-Premise** — Bevor du Cloud-Lösungen unterschreibst
4. **Frag nach Tests** — Bevor du "es funktioniert" glaubst

Wenn du entwickelst:

1. **Schreibe Tests** — Bevor du Code schreibst
2. **Dokumentiere Entscheidungen** — Bevor du vergisst warum
3. **Baue Module** — Bevor du Monolithen baust
4. **Automatisiere** — Bevor du manuell arbeitest
