# Verwaltung 2.0 — Unix-Philosophie für Öffentliche Verwaltungen

> "Weniger, aber wesentlicher. Transparent. Resilient."

## Das Konzept

Anwendung der minimalen stoischer Unix-Prinzipien auf öffentliche Verwaltungen:

- **Einfachheit** — Do one thing well (modulare Fachverfahren)
- **Transparenz** — Text über Binär (API/JSON, Markdown, Git)
- **Resilienz** — Automatisierte Qualität (CI/CD, Tests, Health Checks)
- **Souveränität** — On-Premise First (Datenhoheit bei Kommune)
