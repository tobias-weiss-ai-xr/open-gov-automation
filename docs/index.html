open-gov-automation

Unix-Philosophie für öffentliche Verwaltungen

Weniger, aber wesentlicher. Transparent. Resilient.

Die 4 Prinzipien

1. Einfachheit

Do one thing well — modulare Fachverfahren

2. Transparenz

Text über Binär — API/JSON, Markdown, Git

3. Resilienz

Automatisierte Qualität — CI/CD, Tests, Health Checks

4. Souveränität

On-Premise First — Datenhoheit bei Kommune
